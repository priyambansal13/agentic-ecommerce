# admin service

Trust & safety back office: **listing moderation**, disputes and seller sanctions. Consumes `catalog.product_submitted.v1` and runs a deterministic pre-screen (counterfeit wording, medical claims, contact details, thin content — stands in for the moderation agent): confident APPROVE (≥ 0.9) is auto-decided (`decided_by = agent`), everything else waits for a moderator. `POST /v1/moderation/:itemId/decision` (moderator, admin; APPROVE | REJECT | REQUEST_CHANGES with note; version-checked) publishes `admin.moderation_decided.v1`. Dashboards: `GET /v1/dashboard/moderation` (moderator, admin — queue items carry `version`, `productId`, `brand`, `category`), `/overview` and `/platform-health` (admin).
