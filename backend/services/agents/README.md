# agents service

Agent gateway (AG-UI), LangGraph runtime and governance. Agents touch domain services only through registered tools (zod → current autonomy / kill switch → OPA over server-side facts → audit hash chain). **Refund agent** (`refund`, default L1 shadow, max L3): consumes `returns.return_requested.v1` → classify (offline heuristics or OpenAI, `MODEL_PROVIDER=auto`) → fraud risk → returns policy → proposal (SHADOW/RECOMMEND/LIVE) → at L3 executes small low-risk refunds via returns. Calls returns + fraud through Kong with the `agents` client token (roles service + agent, `X-Agent-Act`; ADR 0015). Admin APIs: `GET /v1/agents/registry`, `PUT /v1/agents/:id/autonomy`, `GET /v1/agents/runs`, `POST /v1/agents/refund/runs`, `GET /v1/agents/:id/evals/latest`; dashboard `GET /v1/dashboard` (real audit data, never seeded). Events: `agent.run_completed.v1`, `agent.escalated.v1`. Evals/release gate: `pnpm --filter @ac/agents run evals -- --agent refund` (needs OPA). Design: platform/docs/03-agentic-ai.md §3.10.
