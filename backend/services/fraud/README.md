# fraud service

Fraud rules v1 for checkout: `POST /v1/internal/risk/score` (role `service`, callers time out at 300 ms and default to REVIEW) — deterministic rules (high value > ₹50k, new account/first order high value, > 3 orders per buyer per hour, ≥ 4 sellers, bulk quantity, blocked pincodes) → score 0–1, ALLOW < 0.4 ≤ REVIEW < 0.8 ≤ BLOCK; idempotent per order (`order_scores`); REVIEW/BLOCK raise an analyst alert; publishes `fraud.order_scored.v1`. Dashboards: `GET /v1/dashboard` (fraud-analyst, admin).
