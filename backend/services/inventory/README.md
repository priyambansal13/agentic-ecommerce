# inventory service

Stock per SKU (sku_id = catalog offer id) and TTL reservations: `POST /v1/internal/reservations` (role `service`; all-or-nothing conditional `UPDATE … WHERE on_hand - reserved >= qty`, lines sorted by SKU, idempotent on orderId, 409 `INSUFFICIENT_STOCK`), `…/:orderId/commit|release`; expiry sweeper every 30 s (`FOR UPDATE SKIP LOCKED`, `RESERVATION_SWEEP_MS`). Consumes `catalog.offer_created.v1` (new SKU), `payment.succeeded.v1` (commit), `payment.failed.v1` / `order.cancelled.v1` (release, or return committed units); publishes `inventory.stock_reserved/reservation_released/stock_committed/low_stock.v1`. Public display stock `GET /v1/stock?skuIds=`; sellers set on-hand with `PUT /v1/sellers/me/stock/:skuId`; every change is logged in `stock_movements`. Dashboards: `GET /v1/dashboard/seller`. Flash-sale guarantee tested by `platform/tests/load/flash-sale.js` (1,000 concurrent buyers, 100 units → exactly 100 reservations).
