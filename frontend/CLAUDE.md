# CLAUDE.md — agentic-commerce / frontend

**Micro-frontends** with Next.js 16.4 **Multi-Zones** (React 19.3, Tailwind v4). One of three repos:
`../platform` (infra, docs, CLI, k3s deploy on Oracle Cloud), `../backend` (microservices + agents), `./` frontend.
Design docs live in **`../platform/docs/`** (micro-frontends doc, `01-hld.md` §1.6, `03-agentic-ai.md` §3.4).

## Zones (`apps/*`, listed in `zones.json`)
| Zone | Port | Path | Owns |
|---|---|---|---|
| `shell` | 3300 | `/` | home, global header/footer, rewrites to all zones (entry point) |
| `storefront` | 3301 | `/shop` | search, product, cart, checkout, shopping assistant |
| `account` | 3302 | `/account` | orders, returns, refund chat |
| `seller` | 3303 | `/seller` | dashboard, listings, inventory, payouts, listing copilot |
| `admin` | 3304 | `/admin` | approvals (agent interrupts), moderation, disputes, fraud console, agent oversight, `/admin/agents/ping` |
Each zone: own `package.json` (`"ac": { kind: "zone", port, basePath, owner }`), `Dockerfile` (standalone),
`.env.local` (generated by `node ../platform/scripts/ac.mjs configure`), independent deploy.

## Shared packages (`packages/*`)
`@ac/ui` (tokens.css, `SiteHeader`, `ZoneLink`) · `@ac/agui-kit` (AG-UI 1.0.3 reducer, `runAgentStream`,
`useAgent`) · `@ac/agent-widget` (`<AgentChat agentId basePath title toolRenderers interruptCards />`) ·
`@ac/bff` (server-only `kongFetch`, `agentRoute`). Backend contracts come as **versioned packages**
`@ac/contracts` / `@ac/money` from the registry (`.npmrc`: `@ac:registry=http://localhost:54873/`) —
never by relative path into `../backend`.

## Commands
```
pnpm install && pnpm build && pnpm test
pnpm dev                                    # all zones; open http://localhost:3300
pnpm dev --filter @ac/zone-shell --filter @ac/zone-storefront   # subset (always include the shell)
pnpm gen zone <name> --base /<path> [--port N]
pnpm update @ac/contracts @ac/money        # after the backend publishes a new version
docker build -f apps/<zone>/Dockerfile -t ac/zone-<zone> .
node ../platform/scripts/ac.mjs doctor      # infra + backend + zones health
```

## Deployment
Production = **k3s on one Oracle Cloud Always Free VM** (ADR `../platform/docs/adr/0011-k3s-on-oracle-cloud.md`).
Each zone runs as its own Deployment/Service `zone-<zone>`, Secret `zone-<zone>`, reachable only from the shell (NetworkPolicy). Images: `ghcr.io/<owner>/ac/zone-<zone>`,
**linux/arm64** (CI on `ubuntu-24.04-arm`). Deploy/rollback one unit from the platform repo:
`ac k8s deploy <env> <name> --tag <sha>` / `ac k8s rollback <env> <name>` (prod only with user approval;
test on `ac k8s local` first) — platform skill `k8s-deploy`.

## Rules
1. **A zone owns its routes, data fetching and agent renderers.** No imports between `apps/*`.
2. **Cross-zone links = hard navigation** (`<ZoneLink>`); `next/link` only inside a zone.
3. **Shared code only via versioned packages**; changes to shared packages are additive and require all
   dependent zones to build.
4. **BFF per zone:** backend calls server-side through `kongFetch`; agent runs through the zone's
   `/api/agents/[agentId]/run` (`agentRoute()`). No tokens, service URLs or secrets in client JS.
5. **Contracts are upgraded deliberately** (`pnpm update @ac/contracts`) — read the changelog.
6. **Agent UI:** facts (prices, amounts, statuses) from tool data, never assistant text; native AG-UI
   interrupts (`RUN_FINISHED` outcome) resumed on the same thread; AI label + classic fallback.
7. **Money** from minor units via `@ac/money`; **Idempotency-Key** on money/stock mutations.
8. **Design tokens** from `@ac/ui` only; both themes; accessible by default.
9. **Docs move with code:** new routes/zones/agent UI → update the platform docs.
