# CLAUDE.md — agentic-commerce / platform

The **platform** repo: architecture docs, local infrastructure, the workspace CLI, the **deployment to k3s on
an Oracle Cloud Always Free VM** (Helm charts + OCI Terraform) and load tests for an Amazon-style marketplace with governed AI agents. Sibling repos: `../backend`
(microservices + agents) and `../frontend` (Next.js micro-frontends). macOS/Linux only.

## Rules
1. **Docs are the source of truth** — any architectural change gets an ADR (`docs/adr/`) and updated
   diagrams/tables in the same change. Mermaid must stay valid.
2. **Metadata-driven platform:** never hard-code service/zone lists; read `backend/services/*/package.json`
   `"ac"` and `frontend/zones.json`.
3. **Isolation is enforced by infra:** one database + role per service, separate env per service/zone,
   one container image and one Kubernetes Deployment + Secret per service/zone, NetworkPolicies
   (services only from `edge`, zones only from the shell, `ac-infra` only from `ac-apps`).
4. **Secrets** never committed, never in Terraform state, images, Helm values files or `NEXT_PUBLIC_*`;
   cluster secrets come only from `deploy/envs/<env>.env` via `ac k8s secrets <env>`.
5. **Destructive or outward actions need the user:** `ac infra reset`, `docker compose down -v`,
   `ac tf oci apply`, `terraform destroy`, `ac k8s deploy prod`, `ac k8s rollback prod`, `helm uninstall`.
6. **Single node, no HA:** keep resource requests within the 12 GB VM; backups must stay green.
7. The CLI must stay idempotent and work on macOS and Linux.
